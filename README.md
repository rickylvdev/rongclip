# RongClip 技术支持 / Support

RongClip 是一款 macOS 菜单栏剪贴板历史工具：自动记录文本、图片与文件，
快捷键一键唤起，搜索即粘贴。所有数据仅存储在本地，不上传、不追踪。

## 常见问题 / FAQ

**如何打开历史面板？**
点击菜单栏剪贴板图标，或使用全局快捷键（可在设置中查看/修改）。

**数据存在哪里？安全吗？**
全部历史仅保存在你 Mac 的本地沙盒容器中，App 不访问网络。

**如何清空历史？**
面板底部的垃圾桶按钮可一键清空。

**支持哪些系统？**
macOS 14.0 及以上。
